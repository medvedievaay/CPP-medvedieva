# Лабораторна робота №3 (ТСПП): проєктування застосунку «August»

Наскрізний проєкт — застосунок мережі супермаркетів «August» (каталог, кошик, оформлення замовлення, програма лояльності). У цьому каталозі зібрано результати проєктування з лабораторної роботи №3: архітектура, модель даних і макети інтерфейсу.

### Архітектурний стиль та архітектурна діаграма

Файл: `architecture-diagram.png`. Для застосунку обрано трирівневу (3-tier) архітектуру, у якій інтерфейс користувача, бізнес-логіка та зберігання даних відокремлені одне від одного. На діаграмі показано три рівні та напрямок взаємодії між ними: клієнтський застосунок звертається до серверної частини, а та працює з базою даних. Такий поділ відповідає специфікації вимог із лабораторної роботи №2.1 і спрощує подальший розвиток кожного рівня окремо.

### ER-діаграма моделі даних

Файл: `er-diagram.png`. Діаграма описує 14 сутностей предметної області (користувачі, товари, замовлення тощо) та зв'язки між ними. Для зручності звітності навмисно застосовано три денормалізації: ціна на момент покупки, сума замовлення та баланс балів лояльності. Діаграма є основою для подальшого створення схеми бази даних.

### Каркас інтерфейсу (wireframe)

Файл: `wireframe.png`. Каркас показує структуру семи екранів застосунку: «Вхід», «Головний», «Каталог», «Картка товару», «Кошик», «Оформлення й оплата» та «Профіль». Він визначає розташування основних елементів і навігацію між екранами, зокрема нижню панель із розділами «Головна», «Профіль» та «Кошик», без деталей візуального оформлення.

### Макет інтерфейсу (mockup)

Файл: `mockup.png`. Макет — це візуально опрацьована версія тих самих семи екранів у стилі сайту August: шрифти Playfair Display (курсив) та Inter, чорні капсульні кнопки, білі картки й плитки товарів із піктограмами. Він демонструє, як застосунок виглядатиме для користувача, та узгоджений із каркасом.
